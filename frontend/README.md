# Document Flow System - Web Client

The frontend user interface for the Document Flow System, designed to interact with the Spring Boot REST API.

## Features
* Integration with the backend for document creation and retrieval.
* Uses modern Angular 20 architecture (Standalone Components, implicit suffixes).
* Reactive forms and manual change detection strategies.

## Development Server

Run `ng serve` (or `npm start`) for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.
